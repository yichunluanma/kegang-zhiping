# 10分钟极速复现指南

版本v0.1.0，2026-10-08。目标是在Node.js 24+环境重现固定样例的完整测评流程，不包含Node安装耗时、外部模型响应或公网部署。

## 路线A：当前电脑 / 离线运行包

0–1分钟：双击根目录“启动课纲智评.cmd”。离线运行包已含KaTeX的生产依赖与前端资源。浏览器自动打开；若没有自动打开，访问 http://127.0.0.1:3210 。

1–2分钟：点击“教师登录”，输入本地演示密码teacher-demo-2026。加载默认示例。

2–3分钟：点击生成蓝图，核对4目标、9题、100分；确认生成试卷。查看两道LaTeX公式。

3–4分钟：编辑任一题的题干或解析，保存。尝试非法公式时系统会拒绝保存。

4–5分钟：点击审核并发布，勾选教师审核确认，打开学生页面。

5–7分钟：填写演示昵称，完成9题；数值填小数/分数/百分数均可。简答内容可参考07-课程样例/演示说明.md。

7–9分钟：回教师端“学情与复核”，刷新，查看答卷，将简答题确认分值保存。查看知识点统计和补练建议。

9–10分钟：导出CSV与完整JSON，完成验收。重启后数据仍保留。

## 路线B：仅源码


根目录的.git保存原始演进。若从离线ZIP开始且需要恢复历史：

```powershell
git clone 'D:\Document\ChuanZhiBei\08-交付包\课纲智评-开发历史.bundle' 'D:\Document\课纲智评-复现'
```

为避免覆盖本项目，请克隆到新的空目录。bundle以真实Git提交为证据；正式提交应推送远程仓库并保留历史。

## 固定演示与真实生成的区别

演示用固定大纲、蓝图和种子1，同一蓝图及种子输出相同题目。具体样例JSON在07-课程样例。

真实模型结果受供应商、版本和采样影响，即使temperature=0.2也不能保证完全逐字一致。可复现性指代码、环境、输入、约束、历史和输出证据可核查；不能声称仅凭Prompt保证模型逐字重现。

## 常见问题

- Node版本不满足：安装Node.js 24+，用node --version确认。
- 3210端口占用：停止原服务，或在.env设置PORT=其它未占用端口。
- npm.ps1被执行策略阻止：使用npm.cmd，不需要更改全局策略。
- 教师登录失败：检查.env中的TEACHER_PASSWORD；服务重启后需要重新登录。
- 模型模式报错：检查模型名称、密钥、兼容JSON输出及接口地址；不得在截图里展示密钥。
- 想跨电脑答题：当前127.0.0.1不接受外部访问；需另行部署，不直接把本地演示密码暴露公网。
