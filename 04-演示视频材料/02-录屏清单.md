# 录屏与素材清单

- [ ] 1920×1080或更高分辨率，浏览器缩放100%，字幕和文字可读。
- [ ] MP4格式，5–8分钟；脚本目标6分30秒。
- [ ] 本人普通话讲解；不添加不存在的使用人数或节省比例。
- [ ] 至少2分钟实际AI协同过程，可展示原始对话、修改指令、实际Bug修复及测试。
- [ ] 至少3个核心功能完整互动链在提交材料中可对应。
- [ ] 录制前准备固定样例与演示昵称，避免显示真实学生信息。
- [ ] 保留模板演示标识；真实模型演示必须实际调用并另存审核记录。
- [ ] 配置页、聊天、终端不展示API密钥或真实密码。
- [ ] 学生作答使用本机窗口；当前链接不可声称公网可访问。
- [ ] 导出后检查全片声音、时长、清晰度和字幕遮挡。

配图位于本目录“配图”；所有图来自实际浏览器自动化验收。它们可以辅助剪辑，但不能代替完整真人讲解和AI过程录屏。没有制作虚假的正式演示MP4。
