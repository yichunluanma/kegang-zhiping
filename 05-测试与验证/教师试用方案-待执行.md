# 教师试用方案（尚未执行）

目标：验证一章课程测评准备是否更方便、题目是否可用；不是直接证明学习成绩提升。

建议先邀请3–5位有对应课程经验的教师。仅记录取得同意的匿名反馈，不收集无必要的个人信息。

每位教师完成两项同等范围的任务：传统方式准备一份测评；使用课纲智评准备一份测评。轮换任务顺序，记录章节与题型差异，避免把不等价任务直接比较。小样本用于产品改进，不做夸大的统计结论。

记录字段：

| 字段 | 定义 |
|---|---|
| 教师匿名编号 | T01等，不填真实姓名 |
| 课程与章节 | 实际使用的大纲版本 |
| 准备时间 | 从任务开始到教师审核完成，包含AI等待和修改 |
| 修改题数 | 教师对题干/选项/答案/解析作实质修改的数量 |
| 修改率 | 修改题数/总题数，统一计算口径 |
| 内容问题 | 错误答案、歧义、超纲、目标不匹配、公式问题分别记录 |
| 目标覆盖 | 按每项具体教学目标检查，不仅检查目标ID存在 |
| 可用性评分 | 1–5分及理由，保留原始匿名反馈 |
| 建议 | 最需要改进的功能与实际场景 |

本项目现有“演示学生A（自动测试）”来自脚本，不属于真实教师或学生试用；不得填入此表冒充用户。

后续教学效果研究应另定实验设计、样本和评价工具。本阶段不宣称效度、信度或能力估计已得到验证。
