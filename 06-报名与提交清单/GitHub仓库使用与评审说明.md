# GitHub仓库使用与评审说明

第一版仓库名称：`yichunluanma/kegang-zhiping`，项目名称“课纲智评”。

仓库用途：保存原创源码、真实细粒度Git历史、运行说明、技术文档、测试记录、课程样例及AI协同过程的现有证据。完整原始AI对话和正式演示视频仍需要补充，不能用现有工程摘要替代。

## 评审访问

第一版先使用私有仓库，便于完善参赛材料。按用户提供的比赛规则，最终需要设为Public或提供评审访问权限。仅提交一个评审无法访问的私有仓库链接不满足要求。

正式提交时，若选择私有仓库，应按比赛平台公布的方法为评审开放访问；若平台不能接收协作者权限，则将仓库公开后再提交。链接地址为 https://github.com/yichunluanma/kegang-zhiping 。

## 历史与复现

上传采用现有本地仓库的普通Git推送，保留原有提交身份、时间、SHA与父提交关系，不重新初始化或压缩为一次提交。后续反馈修复继续追加真实提交。

README提供克隆与启动命令。新电脑需要Node.js 24+；首次源码启动安装固定依赖。Windows启动入口直接使用Node.js，不依赖旧PowerShell脚本。12项自动化测试可在01-应用源码中用 `npm.cmd test` 执行。

## 提交范围

包含源码、package-lock、.env.example、公式资源与第三方许可、技术PDF及可编辑材料、演示脚本、测试证据。

排除node_modules、真实.env、API密钥、SQLite数据库、运行日志、启动令牌、临时验收目录、离线ZIP和Git bundle。离线包保存在本地08-交付包目录；GitHub“Download ZIP”不是附带依赖的离线运行包，也不保存提交历史。
