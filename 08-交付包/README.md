# 交付包说明

- 课纲智评-v0.2.0-离线运行包.zip：源码、KaTeX生产依赖、课程样例、技术文档、演示脚本与验收证据。解压到独立目录，安装Node.js 24+后双击启动，无需npm联网安装即可使用模板模式。
- 课纲智评-开发历史.bundle：本地真实Git演进快照，可git clone恢复；用于离线恢复历史；远程仓库状态以GitHub实际页面为准。
- 文件校验清单.json：ZIP有效载荷的大小与SHA-256；不对清单自身求哈希。

包内不包含真实.env、API密钥、本机SQLite数据库或运行日志。解压后会创建新的演示数据库；本机原目录中的自动化测试答卷不会被复制进包。

2026-10-08启动修复：启动和停止CMD直接使用Node.js，旧PowerShell入口已移除。启动后服务在后台运行，双击“停止课纲智评.cmd”停止；失败提示保留在窗口，服务诊断日志位于01-应用源码/data。

离线包排除本应用不使用的node_modules/.bin命令包装文件（包含npm生成的PowerShell包装）；运行库与前端公式资源完整保留。

本包仍需要Node.js运行环境，不包含操作系统级运行时。模板模式无需外网；真实模型模式仍需有效密钥及网络。正式MP4、完整聊天导出、真实教师试用和远程仓库权限仍待补充，不能把本包当作完全符合最终条件的提交件。

重建包：在项目根目录运行 `python 08-交付包/build_delivery.py`。先运行 `git bundle create 08-交付包/课纲智评-开发历史.bundle --all`，再打包，可保留最新历史。Python只需要标准库。
