# 课纲智评 · 第一版交付说明

面向职业教育的自然语言测评生成与学情反馈平台。命题范围4：低代码与智能表单生成引擎。

本版从空目录原创开发，包含可运行应用、细粒度Git历史、复现指南、技术文档、测试记录和演示脚本。**这是第一版，不是已经满足全部条件的最终参赛提交包。**

## 从GitHub获取并运行

仓库：`yichunluanma/kegang-zhiping`。请使用Git克隆，以保留完整演进历史：

```powershell
git clone https://github.com/yichunluanma/kegang-zhiping.git
Set-Location -LiteralPath 'kegang-zhiping'
.\启动课纲智评.cmd
```

需要Node.js 24或更新版本。Git仓库不包含node_modules，首次启动会运行npm安装固定依赖，需要联网；已安装依赖后，模板演示模式可离线使用。GitHub的“Download ZIP”只提供所选版本的文件，不包含Git历史。

以下文件仅在本地交付目录提供：离线运行ZIP、Git历史bundle、自动生成的文件校验清单。它们未作为源码文件提交。真实模型密钥、运行数据库、学生作答数据及日志均排除在Git仓库之外。

## 立即体验

1. 双击本目录的 **启动课纲智评.cmd**。本机已安装依赖；新电脑需安装Node.js 24或更新版本。
2. 打开 http://127.0.0.1:3210 。点击“教师登录”，本地演示密码为 `teacher-demo-2026`。
3. 点击“生成考核蓝图” → “确认蓝图并生成试卷” → 逐题审核 → “审核并发布”。
4. 打开发布后的学生页面，用演示昵称答题，再回教师端“学情与复核”复核简答题。

学生链接目前只能在本机使用。启动后服务在后台运行，浏览器会在服务就绪后自动打开；双击 **停止课纲智评.cmd** 可停止应用。测评数据保存在SQLite，下次打开仍可查看。数据库中的“演示学生A（自动测试）”来自自动化验收，不是真实教学试用。

## 演示模式和模型模式

默认**模板演示模式**，不调用大模型。它只支持内置《人工智能基础·分类模型评价》大纲、均衡模板及“增加计算题”示例。改变蓝图可调整分值，但题型与目标组合受演示题库限制。不能据此宣称任意课程都能自动生成。

真实模型接入已实现，使用兼容 `/chat/completions` 且支持 `response_format: json_object` 的接口。在01-应用源码复制 `.env.example` 为 `.env`，填写 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL` 后重启。密钥不要放入浏览器、Git或参赛材料。

**当前没有提供真实API密钥，只验证了本地模拟接口契约，没有验证任何真实供应商的效果、费用或延迟。** 模型失败会报错，不会悄悄切换模板。正式使用前，需要实际生成、教师审核及实测。
